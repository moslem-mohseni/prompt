## کاربرد

کد صفحه را از نظر موبایل، راست‌به‌چپ و وابستگی خارجی بررسی کنید.

## قالب

```
<code>
{{code}}
</code>

کد داخل code را فقط ممیزی کن و ایرادها را در یک جدول بده (مشکل، خط یا
بخش، اصلاح پیشنهادی). بررسی‌ها:
- dir="rtl" و lang="fa"؛ ترتیب و آینه‌شدن چیدمان
- ریسپانسیو: نقطه‌های شکست، نبودن اسکرول افقی، هدف لمسی دست‌کم ۴۸ پیکسل
- وابستگی به hover
- کنتراست متن (WCAG AA)
- هر منبعی که از سرور خارجی بارگذاری می‌شود (فونت، کتابخانه، تصویر)
- لینک‌های tel با ارقام انگلیسی
- تگ‌های title، description و Open Graph
هنوز کد را بازنویسی نکن؛ اول فهرست را بده.
```
