fields:
  - key: role
    label: نقش کاربردی مدل (دیدگاه، مخاطب، معیار)
    type: textarea
    required: true
    help: نقش کاربردی، نه نمایشی. «بهترین کپی‌رایتر جهان» کمکی نمی‌کند.
  - key: context
    label: زمینه (مخاطب خروجی، موقعیت استفاده، آنچه مدل نمی‌داند)
    type: textarea
    required: true
  - key: rules
    label: قاعده‌ها، هر کدام با دلیل
    type: textarea
    required: true
  - key: output_format
    label: قالب خروجی
    type: textarea
    required: true
  - key: task
    label: دستور نهایی (یک جمله)
    required: true
    example: برگه را بنویس.
examples:
  sara:
    role: تو دستیار نوشتن برگه‌ی تمرین خانگی برای یک روان‌درمانگری. معیارت این است که برگه بدون توضیح درمانگر قابل فهم باشد.
    context: مخاطب برگه بزرگسال با سواد متوسط است، بدون آشنایی با اصطلاحات روانشناسی، و برگه را در خانه و بدون درمانگر پر می‌کند؛ اغلب وقتی مضطرب است و تمرکز کمی دارد.
    rules: |-
      - یک صفحه‌ی A4 قابل چاپ، چون برگه روی یخچال یا دفترچه می‌ماند.
      - چهار ستون: موقعیت، فکر خودکار، احساس و شدتش از ۰ تا ۱۰، فکر جایگزین.
      - یک ردیف مثال پرشده از یک موقعیت روزمره و غیرحساس، چون مراجع از مثال بهتر می‌فهمد تا توضیح.
      - جمله‌ها کوتاه و بدون اصطلاح تخصصی، چون فرد مضطرب متن بلند نمی‌خواند.
      - مراجع را «شما» خطاب کن.
    output_format: یک راهنمای حداکثر سه‌خطی بالای برگه، بعد جدول چهارستونی با یک ردیف مثال و پنج ردیف خالی، و در پایان «سؤال‌هایتان را در جلسه‌ی بعد بپرسید».
    task: برگه‌ی تمرین ثبت افکار را بنویس.
