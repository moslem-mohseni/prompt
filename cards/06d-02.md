## کاربرد

از فهرست‌های فارسی انتخاب کنید؛ پرامپت انگلیسی فیلم‌برداری تحویل بگیرید.

## قالب

```
{{shot}} of {{subject}}, {{camera}}. {{action}}{{#environment}}; {{environment}}{{/environment}}.
{{#keep}}{{keep}}
{{/keep}}{{light}}, {{style}}.
{{#sound}}{{sound}}
{{/sound}}{{ratio}}, {{duration}}{{#loop}}, {{loop}}{{/loop}}.
```

## ترجمه برای خودتان

```
{{shot:label}} از سوژه ({{subject}})، {{camera:label}}. کنش: {{action}}{{#environment}}؛ محیط: {{environment}}{{/environment}}.
{{#keep}}{{keep:label}}.
{{/keep}}نور: {{light:label}}. سبک: {{style:label}}.
{{#sound}}صدا: {{sound:label}}.
{{/sound}}{{ratio:label}}، {{duration:label}}{{#loop}}، {{loop:label}}{{/loop}}.
```
