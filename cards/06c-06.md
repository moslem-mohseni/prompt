## کاربرد

فایل نهایی یک‌تکه و بدون وابستگی خارجی، آماده‌ی هاست.

## قالب

```
فایل نهایی این صفحه را برای انتشار روی یک هاست ساده آماده کن:
- همه‌ی CSS و JavaScript داخل همان فایل HTML باشد.
- هیچ فونت، کتابخانه یا تصویری از سرور خارجی بارگذاری نشود؛ فونت از
  فایل محلی fonts/Vazirmatn-Regular.woff2 خوانده شود، چون سرورهای خارجی
  برای کاربر داخل ایران ممکن است کند یا در دسترس نباشند.
- راه تماس: {{contact}}
- تگ‌های Open Graph: عنوان «{{og_title}}»، توضیح «{{og_desc}}»، تصویر
  {{og_image}}
- فاوآیکون ساده اضافه شود.
کل فایل را در یک بلوک بده و در پایان فهرست فایل‌هایی را بنویس که باید
کنارش روی هاست بگذارم.
```
