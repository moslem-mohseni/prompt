# بانک پرامپت — راهنمای فنی

سند طراحی و فهرست پرامپت‌ها: `../prompt-bank-plan.md`.

## ساختن

فقط Node نسخه‌ی ۱۸ یا بالاتر؛ هیچ بسته‌ای نصب نمی‌شود.

```
node build/build.js          بررسی و ساخت؛ خروجی در dist/
node build/build.js --check  فقط بررسی
```

## دیدن

```
cd dist
python -m http.server 8743
```

بعد `http://localhost:8743`. دکمه‌ی کپی و حالت آفلاین فقط روی HTTPS یا localhost کامل کار می‌کنند.

## افزودن یا ویرایش پرامپت

1. یک فایل در `cards/` بسازید (نزدیک‌ترین پرامپت را کپی کنید). قالبش در سند طراحی آمده.
2. شناسه‌اش را در دسته‌ی مناسب در `data/categories.json` بگذارید؛ ترتیب همان‌جا تعیین می‌شود.
3. `node build/build.js` را اجرا کنید تا خطایی نماند.

فیلدهای «برند من»: `data/brand.json`. ابزارها و نشانی‌ها: `data/tools.json`. نمونه‌ها: `data/personas.json`. هم‌معنی‌های جست‌وجو: `data/search.json`. بلوک‌های مشترک: `cards/_partials/`.

## انتشار

1. در `bank.config.json` مقدار `base_url` را نشانی نهایی بگذارید.
2. اگر Gemهای آماده را ساخته‌اید، لینکشان را در فیلد `link` کارت‌های `G-01` تا `G-04` بگذارید.
3. `version` را بالا ببرید، بسازید و `dist/` را روی هاست با HTTPS بگذارید. کاربران نصب‌شده نسخه‌ی تازه را خودکار می‌گیرند.

`dist/print.html` نسخه‌ی چاپی همه‌ی پرامپت‌هاست (از مرورگر «ذخیره به PDF»). `dist/qr.svg` کد QR نشانی بانک برای اسلاید است.
